# Use bUI from a CDN (wip)
If you are using a non-js based framework, this is for you.

Just add this to the head of the webpage!
```html
<link href="some_link_to_bmore_file_server/bui.css" rel="stylesheet" type="text/css" />
<script src="some_link_to_bmore_file_server/bui.js"></script>
```
