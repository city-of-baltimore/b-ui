# Usage
If you are building a web product, this is for you.

## Self-hosted Files

Download <a href="./b-ui.css" download>b-ui.css</a> and <a href="./b-ui.js" download>b-ui.js</a>,
then add them to your project files.

To use it, add this to the `<head>` of the webpage!
```html
<link href="path/to/b-ui.css" rel="stylesheet" type="text/css" />
<script src="path/to/b-ui.js"></script>
```

You're ready to use **bUI**. You can use the [design tokens](/docs/design-system-tokens--docs)
by themselves, or use the [web components](/docs/web-components-readme--docs).
