# OPI Component Library (bUI)

A collection of [web components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components)
that uses design tokens provided by the [design system](https://github.com/city-of-baltimore/design-system).

## Development

###  Setup dev environment
Tools: 
- [just](https://github.com/casey/just#cross-platform)
- [watchexec](https://github.com/watchexec/watchexec#install)
- nodejs/npm

Install dependencies
```
npm i
```

### Preview components with [storybook](https://storybook.js.org)
```
npm run storybook

# or
just storybook
```

### run to find more `just` commands or open the `justfile`
```
just
```
